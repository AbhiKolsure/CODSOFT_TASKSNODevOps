# Feature branch example note

This harmless Markdown file is a target for the feature-branch exercise in the Task 2 README. Review the diff after making practice edits; this example does not imply that a pull request was opened or reviewed.

A Git feature branch is a separate line of work for a focused change. Developers use feature branches to keep `main` stable while changes are developed and tested independently. Before merging, the proposed changes can be reviewed by teammates and updated based on their feedback.
